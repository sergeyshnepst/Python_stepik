### Слияние отсортированных по возрастанию списков
```python
def quick_merge(list1, list2):
    result = []

    p1 = 0  # указатель на первый элемент списка list1
    p2 = 0  # указатель на первый элемент списка list2

    while p1 < len(list1) and p2 < len(list2):  # пока не закончился какой-нибудь из списков
        if list1[p1] <= list2[p2]:
            result.append(list1[p1])
            p1 += 1
        else:
            result.append(list2[p2])
            p2 += 1

    if p1 < len(list1):   # прицепление остатка
        result += list1[p1:]
    else:                 # иначе прицепляем остаток другого списка
        result += list2[p2:]
    
    return result

# вызов метода слияния отсортированных списков с подачей числа списков и самих списков
total_list = []
for i in range(int(input())):
    num = [int(q) for q in input().split()]
    quick_merge(total_list, num)
    total_list = quick_merge(total_list, num)
print(*total_list)
```

# Мнимая единица i при умножении на i "циклически" проходит через 4 различных значения:
1 · i = i
i · i = −1
−1 · i = −i
−i · i = 1

Чему равно значение i⁷?
принцип не сложен, знаем, что i² = −1, значит i⁴ = 1, получаем метод:
Степень i делим на 4 - смотрим остаток (в нашем случае 7 % 4 = 3):
- если полученный остаток - ноль, то ответ: единица (как и для всех степеней, кратных четырем)
- если единица, то ответ: i, 
- если двойка, то ответ: минус единица (т.к. i² = −1),
- если тройка, то: минус i.
или: i⁷ = i⁴· i³ = 1 · i³ = i³ = −i
или: i¹⁰⁰ = (i²)⁵⁰ = (-1)⁵⁰ = 1; i⁵⁵ = (i²)²⁷ · i = -i

Комплексные числа обычно обозначаются буквой

Действительная часть комплексного числа обозначается как Re(z)=a,

# Модулем комплексного числа 
z=a+bi 
называется вещественное число, равное
|z| = √(a² + b²)
Для z = 3 + 4i:
|z| = √(3² + 4²) = √(9 + 16) = √25 = 5
для нахождения модуля комплексного числа используется встроенная функция abs()
'--------------------------'
Пусть z₁ = a + bi, z₂ = c + di
✅ Сложение комплексных чисел:
z₁ + z₂ = (a + bi) + (c + di) = (a + c) + (b + d)i

✅ Разность комплексных чисел:
z₁ − z₂ = (a + bi) − (c + di) = (a − c) + (b − d)i

✅ Умножение комплексных чисел:
z₁ ⋅ z₂ = (a+bi) ⋅ (c+di) = ac + adi + bci + bdi² = (ac − bd) + (ad + bc)i

✅ Число z̄=a−bi называется сопряженным к числу z=a+bi. 
Произведение двух сопряженных чисел является вещественным числом. Действительно:
z ⋅ z̄ = (a + bi) ⋅ (a − bi) = (a² + b²) + (−ab + ab)i = a² + b²
При умножении сопряженных комплексных чисел возникает i², значение которого равно −1.

✅ Деление комплексных чисел:
z₁/z₂=(a+bi)/(c+di)=(a+bi)(c−di)/(c+di)(c−di)=[(ac+bd)+(bc−ad)i]/(c²+d²)=(ac+bd)/(c²+d²)+(bc−ad)/(c²+d²)⋅i

Таким образом, для того, чтобы поделить два комплексных числа, мы умножаем числитель и знаменатель дроби 
на число сопряженное к знаменателю, в результате в знаменателе оказывается вещественное число!
При делении комплексных чисел возникает i², значение которого равно −1.
Пример. Пусть z₁ = 3 + 2i, z₂ = 1 + 7i, тогда

## Функции высшего порядка
### Самописные функции map(), filter(), reduce()
```python
def map(function, items):
    result = []
    for item in items:
        new_item = function(item)
        result.append(new_item)
    return result
```
```python
def filter(function, items):
    result = []
    for item in items:
        if function(item):        
            result.append(item)  # добавляем элемент item если функция function вернула значение True
    return result
```
```python
def reduce(operation, items, initial_value):
    acc = initial_value
    for item in items:
        acc = operation(acc, item)
    return acc
```
✅**Функции высшего порядка** — это функции, которые принимают другие функции в качестве аргументов и/или возвращают функции в качестве результата.\
✅**Предикат** — это функция-критерий, которая возвращает значение True или False.\
✅**Агрегация результата** — формирование одного результирующего значения при комбинации элементов с использованием аргумента-аккумулятора.
